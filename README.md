# Blog API

A RESTful Blog API developed using **Python, Django, and Django REST Framework (DRF)**. This project provides backend APIs for managing blog posts and users through standard HTTP requests.

## Features

* User registration and authentication
* Create, read, update, and delete blog posts
* RESTful API endpoints
* Django REST Framework serializers
* Database integration using Django ORM
* URL routing and API views
* Validation and error handling



## Technologies Used

* Python
* Django
* Django REST Framework
* SQLite/MySQL
* HTML/CSS (if applicable)
* Git & GitHub

## Purpose

The main purpose of this project is to understand and implement **REST API development using Django REST Framework** and to gain practical experience with backend development, CRUD operations, database management, authentication, and API architecture.

## API Operations

The API supports common CRUD operations:

* **GET** — Retrieve blog posts
* **POST** — Create a new blog post
* **PUT/PATCH** — Update an existing blog post
* **DELETE** — Delete a blog post
